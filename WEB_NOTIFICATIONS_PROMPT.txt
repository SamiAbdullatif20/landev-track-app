1. **Poll** (every 60s while logged in): `GET` unread count using Bearer token and/or session cookie (same auth as other tracking APIs).
2. **Badge:** Shows red count when unread > 0.
3. **Click:** Opens `{webAppBaseUrl}/notifications` in the default browser, clears badge immediately, calls mark-seen API.

### URL resolution

- Default page: **`/notifications`** on the same origin as `VITE_API_BASE_URL` (without trailing `/api`).
- Example: API `https://landev.vercel.app` → opens `https://landev.vercel.app/notifications`
- Optional env overrides on desktop: `VITE_WEB_APP_URL`, `VITE_WEB_NOTIFICATIONS_PATH`

## Required API endpoints

Desktop tries these paths **in order** (404 → next). Implement **at least one** unread endpoint and **at least one** mark-seen endpoint.

### Unread count (GET)

Preferred:

```
GET /api/notifications/unread-count
```

Alternates tried:

- `GET /api/notifications/unread`
- `GET /api/notifications/count`

**Response (any of these shapes work):**

```json
{ "unreadCount": 3 }
```

```json
{ "count": 3 }
```

```json
{ "unread": 3 }
```

```json
{ "data": { "unreadCount": 3 } }
```

Auth: same session as `/api/auth/me` — cookie and/or Bearer.

### Mark seen (POST)

When user clicks the bell, desktop calls:

```
POST /api/notifications/mark-all-read
```

Body:

```json
{ "source": "desktop-tracker" }
```

Alternates tried:

- `POST /api/notifications/read-all`
- `POST /api/notifications/mark-seen`

**Expected:** 200/204; subsequent unread count = 0 (until new notifications arrive).
