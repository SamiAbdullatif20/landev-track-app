## Session flow

1. Desktop starts capture locally, then `POST /api/tracking/session/start` → needs **`sessionId`** in response.
2. Events/screenshots may lack `sessionId` for a few seconds; desktop backfills then syncs — **accept and link by session id**.
3. Stop: `POST /api/tracking/session/stop` with `stoppedAt`, `startedAt`, `workDateKey`, `clientTimeZone`, `trailingEvents`.

## Ingest rules

1. **`eventUuid`** unique — retries return 200, no duplicate rows.
2. **`uploadUuid`** unique for screenshots — same.
3. Accept `INPUT_ACTIVITY`, `APP_FOCUS`, `ACTIVITY_INTERVAL` without failing batch on optional/future kinds.
4. Persist full activity metrics, not only efficiency percent.
