## Product rules (must match desktop)

### Time
- **Duration = `stoppedAt − startedAt`** (UTC timestamps), clamped ≥ 0.
- Prefer stored `durationMs` when it matches timestamp math within **1 second**.
- Day total = **sum of all WorkSession segments** for `userId + workDateKey` (local calendar day in `clientTimeZone` / stored `workDateKey`).
- Live open session (no `stoppedAt`): include `now − startedAt` for that day’s portion only.
- **Never** subtract idle / inactivity / activity threshold from report totals.

### Projects
- Show `projectName` / display label from the session.
- Support catalog/admin names like `Admin - New Task` (may be non-chargeable).
- Aggregate time **per project** for the day when the design shows a project breakdown (same project → sum durations).

### Sessions
- Multiple Start/Stop cycles in one day = **multiple segments**. Report must list **all**, not only the latest.
- Each row should show at least: project, description, start time, stop time, duration.

### Screenshots
Desktop upload path is **direct to Supabase storage**, not Vercel multipart:

1. `POST /api/tracking/screenshots/sign` — JSON only → signed Supabase URL  
2. Desktop `PUT`s JPEG bytes **directly to Supabase**  
3. `POST /api/tracking/screenshots/commit` — JSON metadata → DB row  

Report UI must:

- Load screenshots linked by `userId + workDateKey` and/or `workSessionId` / `sessionId`
- Show all screenshots for the **selected day** (all segments), not only the active/latest session
- Use signed **read** URLs from storage (or existing screenshot list API) — do **not** re-upload through Vercel
- Cadence context (informational): first capture ~**1 minute** after session start, then every **~20 minutes** until stop
- Deduplicate by `uploadUuid` if present

### Apps used (if shown in the design)
- `APP_FOCUS` / apps-used is **evidence only** — never modify duration totals.
