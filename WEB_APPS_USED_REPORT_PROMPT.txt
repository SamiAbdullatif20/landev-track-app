- No activity-score deductions on duration

### Screenshots (unchanged)

2. Desktop uploads JPEG **directly to Supabase** (not Vercel multipart)

### Apps used (NEW — just added on desktop)
While a session is **active**, desktop:

- Samples foreground Windows app every **~3 seconds**
- Emits **`APP_FOCUS`** events on app change, or every **~15 seconds** while the same app stays focused
- Filters out shell noise client-side: `powershell`, `pwsh`, `cmd`, `conhost`, `wt`, `openconsole`
- Shows a local **“Apps used today”** list (display name + time)
- Queues events offline and syncs via batch ingest
- Sends friendly names when possible (e.g. Google Chrome, AutoCAD, Zoom, Teams, VS Code)

## Tracking report: Apps used panel

For selected `userId` + `workDateKey`:

1. Load **all** `APP_FOCUS` events for that employee/day across **all** `workSessionId`s (multi start/stop same day = append, don’t replace).
2. Aggregate:

```ts
function aggregateAppsUsed(events) {
  const byName = new Map();
  for (const e of events) {
    if (e.eventKind !== "APP_FOCUS") continue;
    const name =
      e.applicationDisplayName ??
      e.appName ??
      (e.processName ? String(e.processName).replace(/\.exe$/i, "") : null) ??
      "Unknown";
    const key = String(name).trim();
    if (!key) continue;
    const lower = key.toLowerCase();
    if (["powershell", "pwsh", "cmd", "conhost", "wt", "openconsole"].includes(lower)) continue;
    byName.set(key, (byName.get(key) ?? 0) + Number(e.activeSeconds ?? 0));
  }
  return [...byName.entries()]
    .map(([name, seconds]) => ({
      name,
      seconds,
      formatted: formatDuration(seconds) // e.g. "47m" or "1:12:05"
    }))
    .filter((row) => row.seconds >= 1)
    .sort((a, b) => b.seconds - a.seconds);
}
```

3. UI (LogWork-like list):

```
Apps used
Google Chrome     0:22:10
AutoCAD           0:47:03
Zoom              0:15:40
```

Rules:
- Prefer **`applicationDisplayName` / `appName`** for labels (not raw slug alone)
- Minutes/time = **SUM(`activeSeconds`)** — not session wall-clock by itself
- Apps used is **evidence**; it must **not** change paid/tracked day total
- Day total remains wall-clock WorkSession sum only
