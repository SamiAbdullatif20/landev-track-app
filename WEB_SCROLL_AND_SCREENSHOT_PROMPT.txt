## 1) INPUT_ACTIVITY changes to consume

Each INPUT_ACTIVITY event can now include:

- `mouseMoveCount` (meaningful movement ticks)
- `clickCount`
- `scrollCount` (new; wheel activity)
- `mouseMovePercent` (0..100, already de-biased)
- `activeSeconds`, `idleSeconds`, `trackerElapsedMs`
- `metadata.mouseMoveSamples`, `metadata.totalSamples`
- `metadata.scrollCount` (same semantic as top-level)

### Mouse activity metric (reporting)

Keep existing time-weighted aggregation for `mouseMovePercent`:

```ts
weightedPct = sum(mouseMovePercent * weightSeconds) / sum(weightSeconds)
```

Where `weightSeconds` is `activeSeconds` fallback `trackerElapsedMs / 1000`.

### New scroll metric (add to API/UI)

Please add a scroll metric in report responses:

- `totalScrollCount = sum(INPUT_ACTIVITY.scrollCount || metadata.scrollCount || 0)`

Optionally expose:

- `scrollEventsPerHour = totalScrollCount / (totalActiveSeconds / 3600)` when active seconds > 0.

Do not break old rows where `scrollCount` is missing.
