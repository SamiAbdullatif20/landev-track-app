## How to compute total tracked time for a work day (REQUIRED)

```ts
function totalTrackedMsForDay(
  workSessions: WorkSession[],
  userId: string,
  workDateKey: string,
  clientTimeZone: string
): number {
  let total = 0;

  for (const session of workSessions.filter((s) => s.userId === userId)) {
    if (!session.startTime || !session.stopTime) continue;

    const overlapMs = overlapLocalWorkDayMs(
      session.startTime,
      session.stopTime,
      workDateKey,
      clientTimeZone
    );
    total += overlapMs;
  }

  return total;
}
```

- Include **every** WorkSession row for that employee whose interval overlaps `workDateKey` (local timezone).
- Multiple Stop/Start segments **add together** — e.g. 3h + 2h + 3h = **8h**, not 3h.

### WRONG (do not use for total hours)

```ts

// ❌ Sum of app focus (under-counts when focus probe gaps, tracker foreground, etc.)

// ❌ Sum of input activity windows

// ❌ Average or max of session durations
```

### RIGHT (use for admin “hours tracked” / timesheet total)

```ts

```

Use `APP_FOCUS` only for **“apps used”** breakdown, not headline hours.

## Cross-midnight sessions

When a session spans local midnight (e.g. 22:00–02:00):

- Split duration across `workDateKey` boundaries using `clientTimeZone`
- June 2 report gets 2h, June 3 report gets 2h — not 0h on one day

Helper logic (same as desktop):

```ts
function overlapLocalWorkDayMs(
  startIso: string,
  endIso: string,
  workDateKey: string,
  timeZone: string
): number {
  const startMs = Date.parse(startIso);
  const endMs = Date.parse(endIso);
  if (!Number.isFinite(startMs) || !Number.isFinite(endMs) || endMs <= startMs) return 0;

  const dayStartMs = resolveLocalMidnightMs(workDateKey, timeZone);
  const dayEndMs = resolveLocalMidnightMs(nextCalendarDate(workDateKey), timeZone);
  return Math.max(0, Math.min(endMs, dayEndMs) - Math.max(startMs, dayStartMs));
}
```
