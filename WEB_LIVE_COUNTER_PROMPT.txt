## Web UI: live counter (required)

The live counter is **client-side**. Do **not** rely on server-pushed duration every second.

```tsx
function useLiveSessionTimer(active: boolean, startedAt: string | null): string {
  const [label, setLabel] = useState("0:00:00");

  useEffect(() => {
    if (!active || !startedAt) {
      setLabel("0:00:00");
      return;
    }
    const startedMs = Date.parse(startedAt);
    if (!Number.isFinite(startedMs)) {
      setLabel("0:00:00");
      return;
    }
    const tick = () => {
      const ms = Math.max(0, Date.now() - startedMs);
      setLabel(formatHms(ms)); // H:MM:SS
    };
    tick();
    const id = window.setInterval(tick, 1000);
    return () => window.clearInterval(id);
  }, [active, startedAt]);

  return label;
}
```

Also:
- Poll active session every **3–5 seconds** to resync `active` + `startedAt` after remote Start/Stop.
- On Stop, show final `durationMs` or `stoppedAt - startedAt` and **stop** the interval.
- Day total (if shown) = sum of completed segments + live open segment.

**Never** use activity / APP_FOCUS sums for the live session clock.
