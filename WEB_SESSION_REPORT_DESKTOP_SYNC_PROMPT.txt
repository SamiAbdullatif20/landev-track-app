# Part 1 — Activity breakdown: Mouse clicks %

## Score rule (do not change)

Headline **Activity score** uses **keyboard + mouse movement only** — not clicks:

```ts
activityScore = round((keyboardActivityPercent + mouseActivityPercent) / 2)
```

Three breakdown rows are **independent**:

| UI label | Field | Seconds field (for aggregation) |
|----------|-------|----------------------------------|
| Keyboard strokes | `keyboardActivityPercent` | `validKeyboardSeconds` |
| Mouse movements | `mouseActivityPercent` | `validMouseSeconds` |
| Mouse clicks | `clickActivityPercent` | `validClickSeconds` or `clickActiveSeconds` |

## `INPUT_ACTIVITY` fields (every ~15s)

Top-level **and** `metadata`:

```json
{
  "eventKind": "INPUT_ACTIVITY",
  "trackerElapsedMs": 15000,
  "clickCount": 4,
  "keyboardActivityPercent": 20.8,
  "mouseActivityPercent": 27.3,
  "clickActivityPercent": 13.33,
  "activityScore": 24,
  "validKeyboardSeconds": 3.12,
  "validMouseSeconds": 4.0,
  "validClickSeconds": 2.0,
  "clickActiveSeconds": 2.0,
  "metadata": {
    "validClickSeconds": 2.0,
    "clickActivityPercent": 13.33,
    "clickSamples": 2
  }
}
```

## `ACTIVITY_INTERVAL` fields (every 15 min)

Also includes `clickActivityPercent` and `validClickSeconds` (top-level + metadata).

## Aggregate clicks for session / day (REQUIRED)

**Sum seconds — do NOT average per-event percents:**

```ts
function aggregateClickActivityPercent(inputActivityEvents: TrackingEvent[]): number | null {
  let clickSeconds = 0;
  let windowSeconds = 0;

  for (const event of inputActivityEvents) {
    const winSec = (event.trackerElapsedMs ?? 15_000) / 1000;
    windowSeconds += Math.max(0, winSec);
    clickSeconds += Math.max(
      0,
      event.validClickSeconds ??
        event.metadata?.validClickSeconds ??
        event.clickActiveSeconds ??
        event.metadata?.clickActiveSeconds ??
        0
    );
  }

  if (windowSeconds <= 0) return null;
  return Math.round((clickSeconds / windowSeconds) * 1000) / 10;
}
```

**Legacy fallback:** if no click fields on any event → show **—** (not 0%). Do not derive % from raw `clickCount` alone.

# Part 2 — Meeting attributed time

## Problem

Meeting time shows nothing because the web never reads `meetingAttributedSeconds`. Desktop now counts:

- **Foreground meetings** — Zoom, Teams, Meet, Webex, Slack huddle, etc.
- **Background meetings** — user shares screen in Zoom and works in another app; meeting window still detected.

## `INPUT_ACTIVITY` fields (every ~15s)

```json
{
  "eventKind": "INPUT_ACTIVITY",
  "trackerElapsedMs": 15000,
  "meetingAttributedSeconds": 12,
  "isMeetingActive": true,
  "meetingPresenceReason": "background_zoom_meeting_window",
  "meetingDetectionSource": "background",
  "meetingPollSamples": 12,
  "activeSeconds": 15,
  "idleSeconds": 0
}
```

## `APP_FOCUS` fields (every ~3–15s)

Same meeting fields when a meeting is active:

```json
{
  "eventKind": "APP_FOCUS",
  "activeSeconds": 15,
  "meetingAttributedSeconds": 15,
  "isMeetingActive": true,
  "meetingPresenceReason": "background_zoom_meeting_window",
  "meetingDetectionSource": "background",
  "metadata": { "meetingPresenceOverride": true }
}
```

### `meetingDetectionSource`

| Value | Meaning |
|-------|---------|
| `foreground` | Meeting app is the focused window |
| `background` | Meeting app open (e.g. Zoom sharing) while user works elsewhere |

### `meetingPresenceReason` examples

`zoom_meeting_window`, `teams_meeting_or_call`, `browser_meeting_title`, `background_zoom_meeting_window`

## Aggregate meeting time for session / day (REQUIRED)

```ts
function aggregateMeetingAttributedMs(inputActivityEvents: TrackingEvent[]): number {
  let meetingSeconds = 0;

  for (const event of inputActivityEvents) {
    const sec =
      event.meetingAttributedSeconds ??
      event.metadata?.meetingAttributedSeconds ??
      0;
    if (sec > 0) meetingSeconds += sec;
  }

  return Math.round(meetingSeconds * 1000);
}
```

**Use `INPUT_ACTIVITY` only** for the headline meeting total (avoids double-count with `APP_FOCUS`). Fallback to `APP_FOCUS` only if no `INPUT_ACTIVITY` rows exist.

**Display:** format as duration (`1h 23m`). Show **—** only for legacy sessions with no meeting fields.
