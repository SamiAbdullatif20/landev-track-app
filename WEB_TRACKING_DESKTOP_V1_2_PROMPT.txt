# 1. Live session timer (fix counter stuck at 0:00)

Employees report the web dashboard timer does **not tick every second** while tracking.

### Rule

The live counter is **not** server-pushed. Compute it in the browser:

```ts
elapsedMs = Date.now() - Date.parse(startedAt)
```

Use `setInterval(tick, 1000)` while `active === true`. Polling alone (every 5s) is not enough.

### `GET /api/tracking/session/active` (and fallbacks `/api/tracking/session/status`, `/api/attendance/today`)

**While tracking:**

```json
{
  "active": true,
  "workSession": {
    "id": "clx...",
    "sessionId": "clx...",
    "projectId": "1604",
    "projectName": "Admin - General",
    "description": "Site drawings",
    "startedAt": "2026-06-02T08:00:00.000Z",
    "startTime": "2026-06-02T08:00:00.000Z",
    "stoppedAt": null
  }
}
```

**While stopped:**

```json
{ "active": false, "workSession": null }
```

Accept start-time field aliases: `startedAt`, `startTime`, `startTimeUtc`, `clockInAt`.

### React hook (copy into dashboard)

```tsx
function useLiveSessionTimer(active: boolean, startedAt: string | null): string {
  const [label, setLabel] = useState("0:00");

  useEffect(() => {
    if (!active || !startedAt) {
      setLabel("0:00");
      return;
    }
    const startedMs = Date.parse(startedAt);
    if (!Number.isFinite(startedMs)) {
      setLabel("0:00");
      return;
    }
    const tick = () => setLabel(formatDuration(Date.now() - startedMs));
    tick();
    const id = window.setInterval(tick, 1000);
    return () => window.clearInterval(id);
  }, [active, startedAt]);

  return label;
}
```

Poll active session every 3–5s to resync `active` + `startedAt`; the 1s interval handles ticking.

### Live segment vs “worked today”

| UI label | Source |
|----------|--------|
| **Live timer** (current segment) | `Date.now() - startedAt` while `active` |
| **Worked today** total | Sum **completed** WorkSession durations for `workDateKey` + live segment overlap |

**Response must include:**


**Ingest rules:**


# 3. Total tracked time (hours worked)

**Headline “time tracked” / timesheet hours** = sum of **WorkSession wall-clock** per `userId + workDateKey`.

```ts
function totalTrackedMsForDay(sessions, userId, workDateKey, clientTimeZone): number {
  let total = 0;
  for (const session of sessions.filter((s) => s.userId === userId)) {
    if (!session.startTime || !session.stopTime) continue;
    total += overlapLocalWorkDayMs(session.startTime, session.stopTime, workDateKey, clientTimeZone);
  }
  return total;
}
```

### WRONG (do not use for billable hours)

- Sum of `APP_FOCUS.activeSeconds`
- Sum of `INPUT_ACTIVITY.trackerElapsedMs`
- Latest WorkSession only
- Activity engagement totals

### RIGHT

- Sum all WorkSession `stopTime - startTime` rows overlapping the day (split at midnight using `clientTimeZone`).

Multi-segment example: 3h + 5h same day = **8h** total.

# 4. Activity / engagement metrics (session report)

Desktop sends `INPUT_ACTIVITY` every **15 seconds** and `ACTIVITY_INTERVAL` every **15 minutes**.

### Engagement (timeline score source)

```json
{
  "eventKind": "INPUT_ACTIVITY",
  "trackerElapsedMs": 15000,
  "activeSeconds": 15,
  "idleSeconds": 0,
  "validEngagedSeconds": 12,
  "engagementActivityPercent": 80,
  "activityScore": 80,
  "activityLevel": "high",
  "timelineColor": "green"
}
```

**Desktop rule:** `validEngagedSeconds = 0` when engagement is **≤ 5%** of the 15s window (`validEngagedSeconds / 15 ≤ 0.05`). Mirror this when aggregating if you recompute from raw polls.

**Aggregate for session/day headline activity %:**

```ts
function aggregateEngagementPercent(events: TrackingEvent[]): number | null {
  let engagedSeconds = 0;
  let windowSeconds = 0;
  for (const event of events) {
    if (event.eventKind !== "INPUT_ACTIVITY" && event.eventKind !== "ACTIVITY_INTERVAL") continue;
    const winSec = (event.trackerElapsedMs ?? 15_000) / 1000;
    windowSeconds += winSec;
    engagedSeconds += event.validEngagedSeconds ?? event.metadata?.validEngagedSeconds ?? 0;
  }
  if (windowSeconds <= 0) return null;
  return Math.round((engagedSeconds / windowSeconds) * 1000) / 10;
}
```

Prefer `validEngagedSeconds` / `engagementActivityPercent` over averaging keyboard + mouse breakdown rows.

### Click activity

Fields: `clickActivityPercent`, `validClickSeconds`, `clickActiveSeconds`, `clickCount`, `clickSamples`

```ts
// Sum seconds, then divide — do NOT average per-event percents
clickActivityPercent = (sum(validClickSeconds) / sum(windowSeconds)) * 100
```

### Keyboard / mouse breakdown (secondary rows)

`keyboardActivityPercent`, `mouseActivityPercent`, `validKeyboardSeconds`, `validMouseSeconds` — show as breakdown only; do not use as headline score when union fields exist.

### Meeting attributed time — REMOVED

- Desktop **v1.1.5+ no longer sends** `meetingAttributedSeconds`, `isMeetingActive`, `meetingPresenceReason`, `meetingDetectionSource`.
- **Hide or remove** the “Meeting attributed time” row on session reports for new sessions.
- Legacy events may still have these fields — show **—** or ignore; do not break ingest if present on old data.

Time in Zoom/Teams counts as **normal session time** (wall-clock) and Zoom/Teams appear under **Apps used**.

# 5. Apps used (APP_FOCUS)

Desktop emits `APP_FOCUS` on foreground app change (~3s) and every 15s tick.

```json
{
  "eventKind": "APP_FOCUS",
  "appName": "AutoCAD",
  "applicationDisplayName": "AutoCAD",
  "application": "autodesk",
  "processName": "acad.exe",
  "windowTitle": "Drawing1.dwg - AutoCAD 2024",
  "activeSeconds": 15,
  "idleSeconds": 0,
  "workSessionId": "clx...",
  "workDateKey": "2026-06-02"
}
```

**Aggregate apps used for session report:**

```ts
function aggregateAppsUsed(appFocusEvents): Array<{ name: string; seconds: number }> {
  const byApp = new Map<string, number>();
  for (const event of appFocusEvents) {
    const name = event.appName ?? event.applicationDisplayName ?? event.processName ?? "Unknown";
    byApp.set(name, (byApp.get(name) ?? 0) + (event.activeSeconds ?? 0));
  }
  return [...byApp.entries()]
    .map(([name, seconds]) => ({ name, seconds }))
    .sort((a, b) => b.seconds - a.seconds);
}
```

Use **`appName` / `applicationDisplayName`** for display (e.g. “Chrome”, “AutoCAD”, “Zoom”, “Teams”) — not raw `application` slug alone.

Do not collapse distinct apps that share a slug. Show all apps with ≥1s credited time.
