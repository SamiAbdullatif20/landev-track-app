## Important: three metrics, one score

The breakdown has **three independent metrics**. The headline **Activity score** uses only two of them:

```ts
// Per 15s sample or 15-min interval (after anti-cheat):
keyboardActivityPercent = (validKeyboardSeconds / trackedSeconds) * 100
mouseActivityPercent      = (validMouseSeconds / trackedSeconds) * 100   // movement + scroll only
clickActivityPercent      = (validClickSeconds / trackedSeconds) * 100   // clicks only

// Headline score — UNCHANGED, do not include clicks:
activityScore = round((keyboardActivityPercent + mouseActivityPercent) / 2)
```

- **Mouse movements %** = cursor moved ≥12px or wheel scrolled (not clicks).
- **Mouse clicks %** = at least one click in a 1-second poll (left/right/middle/x-button).
- **Keyboard strokes %** = key presses in the window.
- Clicks are **separate** from movement; a click-only second counts for clicks, not movement.

## Per-event semantics (do NOT reinterpret)

**Click % per 15s window:**

```ts
clickActivityPercent = (validClickSeconds / (trackerElapsedMs / 1000)) * 100
```

- `validClickSeconds` ≈ number of 1-second polls with ≥1 click × 1 second, capped at window length.
- Denominator is the **full sample window** (usually 15s), same as movement and keyboard.
- Anti-cheat may zero clicks: `repetitive_clicking` → `validClickSeconds = 0`.

## Session / day report aggregation (REQUIRED)

**Sum seconds across events — do NOT average per-event percents** (same rule as mouse movement fix).

```ts
function aggregateActivityBreakdown(inputActivityEvents: TrackingEvent[]) {
  let keyboardSeconds = 0;
  let mouseSeconds = 0;
  let clickSeconds = 0;
  let windowSeconds = 0;

  for (const event of inputActivityEvents) {
    const winSec = (event.trackerElapsedMs ?? 15_000) / 1000;
    windowSeconds += Math.max(0, winSec);

    keyboardSeconds += Math.max(
      0,
      event.validKeyboardSeconds ??
        event.metadata?.validKeyboardSeconds ??
        0
    );
    mouseSeconds += Math.max(
      0,
      event.validMouseSeconds ??
        event.metadata?.validMouseSeconds ??
        event.mouseActiveSeconds ??
        event.metadata?.mouseActiveSeconds ??
        0
    );
    clickSeconds += Math.max(
      0,
      event.validClickSeconds ??
        event.metadata?.validClickSeconds ??
        event.clickActiveSeconds ??
        event.metadata?.clickActiveSeconds ??
        0
    );
  }

  if (windowSeconds <= 0) {
    return {
      keyboardActivityPercent: null,
      mouseActivityPercent: null,
      clickActivityPercent: null,
      activityScore: null
    };
  }

  const keyboardActivityPercent = round1((keyboardSeconds / windowSeconds) * 100);
  const mouseActivityPercent = round1((mouseSeconds / windowSeconds) * 100);
  const clickActivityPercent = round1((clickSeconds / windowSeconds) * 100);
  const activityScore = Math.round((keyboardActivityPercent + mouseActivityPercent) / 2);

  return {
    keyboardActivityPercent,
    mouseActivityPercent,
    clickActivityPercent,
    activityScore
  };
}

function round1(n: number) {
  return Math.round(n * 10) / 10;
}
```
